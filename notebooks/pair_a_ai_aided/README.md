# Pair A (AI-Aided) Workspace

Welcome to the **AI-Aided** workspace for Phase I.

## Rules & Protocol (AI4Vis Track)
- **Active GenAI Usage:** Use Generative AI (LLMs, chat assistants) to brainstorm analytical questions, generate code snippets, build interactive visual controls (e.g., Plotly, Streamlit, Matplotlib widgets), and interpret anomalies.
- **Mandatory AI Log:** Document significant prompts, accepted/rejected suggestions, and observed AI hallucinations/errors in `ai_logs/phase1_ai_log.md`.
- **Higher Fidelity:** Expected to leverage AI acceleration to explore richer interaction or broader analytical scope.

## Starter Files
- `phase1_visual_analytics.py`: Telemetry vs model degradation curves and strategy timeline.
- `red_bull_analysis.py`: Head-to-head comparison of VER vs PER on Medium tyres.
